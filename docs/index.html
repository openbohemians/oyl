Build and Run

Build with a C11 compiler (GCC/Clang tested on Linux and macOS).

make              # build liboyl.a
make test-all     # run all tests
make test-suite   # run YAML Test Suite (needs submodules)
make bench        # scanner benchmark on your machine

Core Capabilities

Scanner

SIMD-accelerated tokenization (SSE4.2 with scalar fallback), producing a flat token stream.

Parser

Event API with indent tracking, block structure handling, merge key expansion, alias resolution, and event safety limits.

Emitter

Roundtrip output in block, flow, or minimal style, with auto-quoting for ambiguous plain scalars.

Schema support: Failsafe, JSON, Core, or fully custom resolution rules.

Architecture

Oyl keeps scanner and parser responsibilities clean: raw tokens first, structure and properties in parser, then emit text.

Quick API Snapshot

Event Loop

const oyl_event *evt;
while (oyl_parse_next(parser, &evt) == OYL_OK) {
  if (evt->type == OYL_EVT_STREAM_END) break;
  /* consume event */
}

Error Reporting

if (oyl_parse_next(parser, &evt) != OYL_OK) {
  const char *msg = oyl_parser_error(parser);
  oyl_mark mark = oyl_parser_error_mark(parser);
  printf("%zu:%zu: %s\n", mark.line, mark.col, msg);
}
